# スクレイピング調査メモ

## 1. 詳細ページへの導線URLパターン（どこから辿るか）
- 一覧・検索など「詳細リンクが載っているページ」をページタイプごとに列挙する  
- 各ページタイプについて、最低限これを書く  
  - URLの共通部分（prefix / 正規表現）
  - そのページに **詳細ページへのリンク** が含まれるか（＋ページング有無）

> 例：`/area/` `/search?`

---

## 2. 詳細ページURLパターン（どれが詳細か）
- 詳細ページのURL例を複数集める  
- 共通点から「詳細ページ判定ルール」を1行で書く  
  - prefix or 正規表現  
- 似ているけど詳細じゃないURLの「除外ルール」も書く（誤爆防止）

> 例：`^https?://paypaygourmet\.yahoo\.co\.jp/\d+/?$`  
> 除外：`/area/` `/t-genre/` `/t-scene/` `/search?`

---

## 3. 詳細ページのデータの取り方（各項目）
項目ごとにこの5つだけ書く（DevToolsでHTML確認して決める）

- 項目名（例：住所）
- ある場所（セクション名 or ラベル）
- 取り方（CSS / XPath / ラベル基準）
- 欠損時の扱い（null/空）
- 整形ルール（必要なら：空白除去、複数値の扱い等）
